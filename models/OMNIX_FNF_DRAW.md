# OmnixFNF-Draw AI

OmnixFNF-Draw is the visual-agent layer for creating original, FNF-compatible 2D assets.

Pipeline:
PNG/reference -> segmentation -> editable parts -> rig -> poses -> expressions -> animation -> spritesheet -> atlas/XML -> preview -> export.

The agent can plan:
- character parts
- layer structure
- poses
- expressions
- animation frames
- sprite-sheet layouts
- OmnixEngine export metadata

For user-owned original characters, the pipeline can preserve visual identity across poses. Avoid claiming exact reproduction of copyrighted game assets; use original or properly licensed references.
