# OMNIX PROCEDURAL SHADERS
Procedural effects are generated mathematically at runtime without PNG, JPG, sprites or external image textures.
Supported concepts: UV, time, BPM, beat phase, sin/cos, atan, distance, fract/floor, smoothstep, hash/noise-like fields, gradients, RGB separation, waves and mathematical glitch.
OmnixShaderChatAI connects shader requests to the configured AI provider.
Examples: dark RGB corruption pulse, procedural vortex, beat-reactive scanlines, mathematical glitch.
OmnixShaderValidator is a lightweight source check that rejects common texture-sampling identifiers.
