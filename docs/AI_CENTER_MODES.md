# Omnix AI Center modes

Each AI Center tab now has a dedicated FNF-focused prompt route.

- CHAT: general FNF assistant
- CODE: Haxe/Lua/code generation
- MOD: mod architecture and asset planning
- DEBUG: error and project diagnosis
- DRAW AI: sprites, poses, rigs and animation planning
- CHART AI: BPM, timing, notes, sections and chart generation

All modes use the same configured local model provider, while the prompt router changes the task specialization.

The model weights are external and are not committed to this repository.
